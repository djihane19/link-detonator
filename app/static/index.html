Link Detonator

An AI agent that investigates links you do not trust, inside a throwaway browser on Vultr. Hostile pages try to hijack the agent. The model only proposes; a rule engine decides, and the sandbox and firewall enforce. You get evidence of what the page tried, what was blocked and what was verified. Then the chamber is destroyed.

  1. DetonateThe link opens in a throwaway browser, in a container behind a firewall. It never clicks, types or submits.
  2. The AI judges, the rules decideThe model reads the evidence and proposes. A rule engine allows or denies every action. The model cannot grant itself anything.
  3. Evidence you can verifyEach claim in the report is tied to recorded events. Containment is shown only when the evidence proves it.

                How a deployed chamber behaves

                • Hands off The browser only looks. No clicks, no typing, no submits, no kept downloads.
                • Walled in On the deployed host, a firewall stops the chamber reaching private networks, cloud metadata or the host itself.
                • No secrets inside Nothing is passed into the container. Evidence leaves through one output stream, treated as hostile.
                • Destroyed, then checked Every chamber is removed after its scan, and the host confirms it is gone.

                None of the four applies in this dev run. The worker is a plain local process.
